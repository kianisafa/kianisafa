# Safa Kiani | Systems Lab

A buildless, interactive portfolio companion. This version is available as source and is not deployed to an external host.

From this directory, run a local static server, for example:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8000/` in your browser. When using the development checkout, serve its `dist/` directory instead.

The rotatable canvas depicts a conceptual systems model. Its layer buttons expose the same content without requiring pointer dragging. The three local simulations use synthetic records and deterministic steps, including a missing-reference review gate. No AI service, customer system, payment provider, analytics or contact form is connected.

The animation respects reduced-motion preferences, includes manual pause and rotation controls, and pauses rendering when outside the viewport. Workflow playback pauses when the page is hidden.

Public project descriptions are based on confirmed portfolio responsibilities. They are separate from the illustrative simulations. Only the public Prestia Trade `.com` website is linked.
